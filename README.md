# رصد اليمن والمملكة

صفحة ترصد هجمات الحوثيين على السعودية والحرب في اليمن، وتتحدث تلقائيًا كل 30 دقيقة عن طريق GitHub Actions.

## كيف يشتغل
- `scripts/update.py` يسحب خلاصة عاجل (RSS) ونتائج Google News من مواقع موثوقة فقط، ويستبعد أي مصدر إماراتي.
- يرسل الأخبار الجديدة لنموذج ذكاء اصطناعي مجاني (Gemini إذا أضفت مفتاحه، وإلا GitHub Models المجاني بتوكن GitHub المدمج) عشان يصنّفها ويكتب عنوان وملخص.
- قواعد منع التكرار في الكود نفسه (نفس المنطقة ونفس الأرقام خلال 3 ساعات = إعلان واحد).
- يحفظ النتائج في `data/news.json` و `data/meta.json`، والصفحة `index.html` تقرأها وتتحدث كل 5 دقائق.

## التشغيل
1. Settings > Pages: المصدر `Deploy from a branch`، الفرع `main`، المجلد `/ (root)`.
2. (اختياري، أدق) Settings > Secrets and variables > Actions > New repository secret: الاسم `GEMINI_API_KEY` والقيمة مفتاحك المجاني من Google AI Studio.
3. Actions > «تحديث الأخبار» > Run workflow لأول تشغيل.

## ملاحظات
- العداد التراكمي للاعتراضات يحسب من 1 أكتوبر 2026، وأخبار الاعتراض تنحفظ دائمًا، والباقي يُحذف بعد 21 يوم.
- أرقام الجيش اليمني رواية طرف واحد، وادعاءات الحوثي تظهر «غير مؤكد».
